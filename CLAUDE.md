# Start here

Read `AGENTS.md` and `docs/REPOSITORY_MAP.md` before editing.

This repository has two active branches: `main` for the published game baseline,
`dev/creation-kit` for the separate development Kit. For Creation Kit work use the
existing Kit worktree and its `docs/handoffs/2026-11-10-claude-opus/START_HERE.md`.
Check branch and worktree status first. Do not develop the Kit on main or merge
archived runtime experiments wholesale. The working app, game, disc and user
projects must be preserved.

The archive tag `archive/runtime-experiments-2026-11-10` preserves historical WIP;
it is not the active Kit baseline. Mockups and old success claims are reference
material, not proof of implementation. Follow the current handoff's acceptance
gates and use Context7/primary documentation when needed.
