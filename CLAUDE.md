# Contributor entry point

Read AGENTS.md and docs/REPOSITORY_MAP.md before editing. Use dev/creation-kit
for editor development and main for the published game baseline. Inspect the
working tree before changing it, preserve user assets/saves, and use separate
editor test profiles. Keep personal handoffs and machine-specific notes local.

Public release notes and README content must describe the product for players.
Never publish local paths, personal names, private handoffs or test-session logs.
